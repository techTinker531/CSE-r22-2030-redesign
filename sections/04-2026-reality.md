# Section 4 — 2026 Reality

| Domain | 2022 Assumption | 2026 Reality |
|---|---|---|
| AI/ML | Classical ML + basic AI | LLMs, RAG, agentic workflows dominant |
| DevOps | Jenkins, manual kubectl, Selenium | GitHub Actions, ArgoCD GitOps, Terraform, Trivy |
| Databases | RDBMS-only (SQL) | Vector DBs standard for RAG apps |
| Security | Perimeter/crypto-only | Zero-trust, cloud IAM, LLM security |
| Compilers | Manual parser theory | LLVM/ANTLR/ESLint-style tooling-first practice |
| Software Delivery | Waterfall/Agile theory | AI coding agents now default: 90% of devs use weekly, 68% daily (JetBrains 2026 Dev Ecosystem Survey, 15,000+ devs) |
| Networking | Static TCP/IP / RIP fundamentals | VPCs, load balancers, Cloudflare-style edge (confirmed by grad interview) |
| Stats/ML sequencing | Prerequisite-before-use assumed | R25 broke this (see Section 3, #1) |

Source: JetBrains Developer Ecosystem Survey 2026 (accessed Sept 2026); grad interview (see [`evidence/human-conversation.md`](../evidence/human-conversation.md)).
