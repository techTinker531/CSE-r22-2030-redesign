Key findings

  • Stats moved into the same semester as ML under R25, breaking a prerequisite gap that R22 kept at three semesters.
  • DevOps structure and credits are untouched in R25 — the problem is tooling. Syllabus still teaches Jenkins, manual kubectl, Selenium; industry has moved to GitHub Actions, ArgoCD, Terraform, Prometheus+Grafana, Trivy+SonarQube.
  • The HKAIVERSE brief's claim that R25 cut DevOps from 4 credits to 1 does not hold — checked against the official bulletin and the uploaded R25 PDF, both show it unchanged.
  • Compiler Design and Formal Languages were merged in R25. Grad interview reframed this from REDUCE to UPDATE — the theory (AST, optimization) still matters, but the delivery should move to modern tooling instead of hand-written parsers.
  • Both open electives on offer are cross-branch, non-CS subjects — evidence the open elective basket isn't doing anything for CS depth.
  • Computer Networks flipped from KEEP to UPDATE after the grad described labs still running RIP in Packet Tracer against a real world of VPCs, load balancers, and edge networking.
  • Git is a double-sourced gap: flagged independently by a job posting and by the grad, who force-pushed to main on day one with no rebase or PR-review training behind them.
  • Cloud Computing already exists as a professional elective in R22 — the fix is promoting it to core, not adding a new course.

Human conversation

2024 CSE grad, now Platform Engineer, Hyderabad. Anonymous, ~20 minutes.

Most outdated course on day one: DevOps lab. College taught Jenkins freestyle jobs, docker run, Selenium IDE. First week: debugging a GitHub Actions YAML and an out-of-sync ArgoCD, having never opened a workflows file before.
Day-one skill the degree never taught: Git beyond commit/push — rebasing, merge conflicts, PR reviews. Force-pushed to main on day one; reverted by their lead.
More valuable in hindsight than it felt then: Operating Systems — semaphores and paging now map directly to pods getting OOMKilled or CPU-throttled in Kubernetes.
One credit they'd add for 2030: "Shipping with GenAI + Cloud" — practical RAG, vector DBs, prompt evaluation, cost control, deploying via Terraform, handling API keys and rate limits.
Did theory-heavy courses hold up? DAA — yes, directly useful for reasoning about production timeouts. Compiler Design's hand-written parser work — rarely used, but AST/optimization concepts still matter if taught through tools like Babel/ESLint.

Section 7 — What would make this wrong

  • The ML/Stats sequencing flaw is wrong if R25 faculty confirm the co-placement was a deliberate just-in-time teaching choice.
  • The DevOps staleness argument is wrong if placement data shows most grads don't enter cloud-native roles.
  • The AI capability test's pattern is wrong if harder, multi-step agentic tasks show AI also handling judgment-based work.
  • The 20–25% credit cap could be too conservative — but the human conversation points to tooling-level gaps, not whole missing domains, which suggests the cap holds.
